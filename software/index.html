      Software and servers

      Servers, code repositories, and prediction tools developed by the lab and its collaborators.

      The lab has a long track record of building web servers and software for protein structure prediction, membrane protein topology, and quality assessment.

      Group repositories

      • GitHub
      • GitLab

      Webservers

      TOPCONS2 (Live)

      Consensus prediction of membrane protein topology and signal peptides.

      SCAMPI2 (Live)

      Membrane protein topology prediction, from a single sequence or a multiple sequence alignment.

      ProQ3 (Live)

      Quality assessment of protein structure models.

      PredZinc (Moving)

      Prediction of zinc-binding residues in proteins.

      Frag1D (Moving)

      Prediction of one-dimensional protein structure: secondary structure and shape strings.

      PRODRES (Moving)

      Fast position-specific scoring matrices (profiles) by searching Pfam domains first.

      NucPred (Live)

      Prediction of nuclear localization of proteins.

      TMDAS (Live)

      Transmembrane helix prediction with the Dense Alignment Surface (DAS) method.

      SVMHC (Live)

      Prediction of peptides binding to MHC class I molecules.

      TOPCONS (v1) (Live)

      The original TOPCONS (2009) consensus topology predictor.

      TOPCONS-single (Live)

      Consensus topology prediction from single sequences, without homology search.

      DGpred (Planned)

      Prediction of the apparent free energy (ΔG) of transmembrane helix insertion.

      KalignP (Planned)

      Multiple sequence alignment with Kalign using position-specific gap penalties.

      mpRAP (Planned)

      Residue accessibility prediction for membrane proteins.

      TMBmodel (Planned)

      3D modelling of transmembrane beta-barrel proteins.

      Databases and browsers

      PconsFam (Planned)

      Predicted structure models for Pfam families.

      CPAfold (Planned)

      Topology annotation and models of CPA/AT transporter families.

      PconsC (Live)

      PconsC contact prediction (former pcons.net).

      Archive (Live)

      Archive of the lab's older web pages and servers.

      TOPCONS2

      Open-source standalone implementation of the TOPCONS membrane-topology predictor.

      TOPCONS2 web server

      Open-source web-server implementation for TOPCONS2.

      PconsC4

      Fast contact prediction software for protein structure modelling.

      PconsC3 web server

      Open-source web-server implementation for PconsC3; deployment source only.

      SubCons web server

      Open-source web-server implementation for subcellular localization prediction.

      fastPSSM web server

      Open-source web-server implementation for fast profile generation.

      FoldDock

      Open-source AlphaFold2-based protein-protein docking protocol.
